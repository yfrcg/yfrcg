## About

I am an undergraduate student majoring in **Computer Science and Technology at Nankai University**.

My current work focuses on building practical AI agent infrastructure: local-first memory, tool execution loops, MCP servers, gateway runtimes, multi-agent workflows, and security-aware automation.

I care about systems that are not only impressive in demos, but also **observable, testable, reproducible, and safe to extend**.

```txt
Build systems that remember.
Design tools that verify.
Ship projects that can be explained.
```

---

## Current Focus

### Agent Runtime & Local-first Memory

I am developing an OpenClaw / Claude Code inspired local agent framework with:

- Long-running Gateway daemon
- Typed WebSocket protocol
- Tool registry and tool-call lifecycle
- Session management and transcript storage
- Markdown + SQLite + BM25 + vector-based memory
- Audit logs, policy checks, and safer execution paths

### MCP for Course Project Intelligence

I am also working on an MCP server for computer science course project discovery and analysis.

It helps agents search, inspect, compare, and reason over course-related open-source projects, while keeping learning context, source quality, and copy-risk awareness explicit.

### Systems & Performance

Beyond agent infrastructure, I also work on lower-level engineering topics:

- SIMD and ARM NEON optimization
- Linux `perf` based hotspot analysis
- SVD / Golub-Kahan optimization experiments
- FPGA / Verilog / Vivado resource analysis
- Database, backend, and course-project engineering
