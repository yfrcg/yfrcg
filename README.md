## 🧭 About

**CS undergraduate @ Nankai University**, working on the underlying infrastructure of AI — turning theoretical concepts into runnable, verifiable, and reproducible systems. Instead of just prompting LLMs, I build the architectures that make them work reliably and locally.

- 🤖 **Agent runtime** — gateway daemons, tool loops, session management
- 🔌 **Tool ecosystems** — Model Context Protocol (MCP) servers and extensions
- 🧠 **Local-first memory** — RAG with hybrid search (vector + BM25) on SQLite
- 🔬 **NLP research** — past research experience in NLP; now focused on agent memory, tool selection & routing
- 🛡️ **Reliability & security** — sandboxing, audit logs, multi-agent verification

> 先跑通，再优化；先验证，再总结；先形成作品，再打磨表达。

## 📖 Recent paper notes

I write in-depth reading notes on agent & NLP papers. Some recent ones:

| Paper | One-line takeaway |
|-------|-------------------|
| **Evo-Memory** — Benchmarking LLM agent test-time learning with self-evolving memory | Not "how to store more", but whether agents can *learn at test time* through a think–act–refine memory loop |
| **SkillRouter** — Skill routing for LLM agents at scale | When agent skills grow to the hundreds, retrieval/routing becomes the bottleneck — a bi-encoder + re-rank pipeline for skill selection |
| **Outcome-Aware Tool Selection for Semantic Routers** | Learning from outcomes as an *offline embedding shift* — zero extra parameters, zero latency, zero GPU at serving time |
| **Real-CE** — A benchmark for Chinese-English scene text image super-resolution | First real-world CN-EN text SR dataset (tri-focal captures) + edge-aware learning to keep dense CJK strokes from blurring |
